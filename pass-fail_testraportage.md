# Go / No-Go Criteria

## GO

* Alle kritische testen succesvol.
* Geen openstaande blocker bevindingen.
* Functioneel akkoord.
* Technisch akkoord.
* Monitoring actief.
* Back-out procedure beschikbaar.

## NO-GO

* Kritische testen mislukt.
* Openstaande blocker bevindingen.
* Beveiligingsissues aanwezig.
* Geen akkoord van stakeholders.
