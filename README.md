##  Overview

This repository contains a structured collection of software test plans developed to support Quality Assurance (QA) activities within the Software Development Life Cycle (SDLC).

The test plans demonstrate a systematic approach to planning, designing, and documenting software testing to ensure that applications meet both functional and non-functional requirements before release.

Each test plan clearly defines scope, objectives, test strategy, risks, and acceptance criteria.

##  What is a Test Plan?

A test plan is an official QA document that defines how a software product will be tested.

It describes:

- What is being tested (scope)  
- Why it is being tested (objectives)  
- How it will be tested (strategy)  
- Which steps are executed (test cases)  
- When tests are considered passed or failed (acceptance criteria)  

---

##  Test Plan Components

###  Scope
Defines which parts of the application are included in testing.

###  Objectives
Defines what the testing process aims to validate.

###  Test Strategy
Describes the overall approach and testing methodology.

###  Test Scenarios
High-level situations that need to be validated.

###  Test Cases
Step-by-step instructions used to verify functionality.

###  Entry & Exit Criteria
Conditions required to start and complete testing.

###  Risk Analysis
Potential risks within the project or system.

###  Acceptance Criteria
Conditions that must be met for approval.

---

##  Types of Testing

###  Functional Testing
Validates that the system behaves according to requirements.

###  Integration Testing
Ensures different modules work together correctly.

###  System Testing
End-to-end testing of the complete system.

###  Regression Testing
Ensures existing functionality is not broken after changes.

###  User Acceptance Testing (UAT)
Testing from the end-user or client perspective.

###  Non-Functional Testing
Includes performance, usability, and reliability testing.

##  Testing Lifecycle

The test plans follow a standard QA process:

1. Requirements Analysis  
2. Test Planning  
3. Test Design  
4. Test Case Development  
5. Test Execution  
6. Defect Reporting  
7. Test Closure & Evaluation
